# Thanks

PeachQ grows through code, documentation, questions and bug reports. Thank you to everyone who helps make it better.

## Contributors and community

Thanks to our code and documentation contributors, including the contributors to the engine PeachQ builds on:

[hetoku](https://github.com/hetoku), [maximk](https://github.com/maximk), [protocolstardust](https://github.com/protocolstardust), [ryanhamilton](https://github.com/ryanhamilton), [ser-vasilich](https://github.com/ser-vasilich), [singaraiona](https://github.com/singaraiona), [theaspirational](https://github.com/theaspirational).

Thanks to [mau-mauricelim](https://github.com/mau-mauricelim) for the table-display and terminal-editing introduction in [issue #62](https://github.com/peachq-org/peachq/issues/62), which helped shape our REPL guide.

Thanks to Michael Keenan for the initial code and core idea behind PeachQ's [C extension support with `2:`](docs/interfaces/c-extensions.md). He is also the author of [qVis](https://github.com/mkeenan-kdb/qVis).

[Documentation for kdb+ and q](https://github.com/KxSystems/docs), by KX Systems
and contributors, through [Ryan Hamilton's fork](https://github.com/ryanhamilton/docs)
at commit [`508a1ae8c8309ac9628aad4f61b8bd8d1d127aeb`](https://github.com/ryanhamilton/docs/commit/508a1ae8c8309ac9628aad4f61b8bd8d1d127aeb).

Links to sections outside that snapshot point to the original KX documentation.
Decorative image embeds were replaced with source links. Four technical images
were copied unchanged from the KX documentation repository at revision
[`b6646cdb9e9ba313ce10b6dc90cc033c244d724f`](https://github.com/KxSystems/docs/tree/b6646cdb9e9ba313ce10b6dc90cc033c244d724f/docs/img).
