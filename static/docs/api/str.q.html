Entity Details

.str.endswith

does s end with suffix? Empty and over-long suffixes as above.

Parameters:
  • s - (any) a string, a symbol, or a list of either
  • suffix - (any) a string or symbol

.str.format

Python-style formatting, same message shape and same DuckDB engine: {} {0} {:>8.2f} {:,}.

Parameters:
  • msg - (any) a format string, or a general list of one plus its arguments

.str.isalnum

is every character a letter or a digit, and is there at least one? NOT .Q.an, which is the IDENTIFIER alphabet and admits "_" - .str.isalnum "a_b" is 0b.

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.isalpha

is every character a letter, and is there at least one?

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.isdigit

is every character a digit, and is there at least one?

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.islower

is every CASED character lower case, and is there at least one? Uncased characters are ignored, so "abc1" is 1b.

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.isspace

is every character one of " \t\n\r", and is there at least one?

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.isupper

is every CASED character upper case, and is there at least one? Uncased characters are ignored, so "ABC1" is 1b.

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.lstrip

leading " \t\n\r" removed.

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.printf

C-style formatting. Grammar and semantics are DuckDB's, so `%'d` groups with an APOSTROPHE and a comma is spelled `%,d`; the q supersets are `%r`, a permissive `%s`, and typed nulls rendering their q display.

Parameters:
  • msg - (any) a format string, or a general list of one plus its arguments

.str.removeprefix

s without a leading prefix, or s unchanged when it does not start with one. Only ONE copy is removed.

Parameters:
  • s - (any) a string, a symbol, or a list of either
  • prefix - (any) a string or symbol

.str.removesuffix

s without a trailing suffix, or s unchanged when it does not end with one. Only ONE copy is removed.

Parameters:
  • s - (any) a string, a symbol, or a list of either
  • suffix - (any) a string or symbol

.str.rstrip

trailing " \t\n\r" removed.

Parameters:
  • s - (any) a string, a symbol, or a list of either

.str.startswith

does s begin with prefix? An empty prefix always does, and a prefix longer than s never does - which is why this is `sublist` and not `#`, whose take WRAPS: 3#"ab" is "aba", so "ab" would wrongly start with "aba".

Parameters:
  • s - (any) a string, a symbol, or a list of either
  • prefix - (any) a string or symbol

.str.strip

leading and trailing " \t\n\r" removed. NOT q's `trim`, whose domain is the char null instead.

Parameters:
  • s - (any) a string, a symbol, or a list of either
