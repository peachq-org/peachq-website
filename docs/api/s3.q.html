s3.q

Configure s3:// reads natively: credentials, region, endpoint and addressing. A config is a dict keyed by the AWS and KX environment variable names, scoped by path prefix and kept inside the process, never in a q variable. The default (scope s3://) resolves as .s3.config[::;::] at the first s3:// read unless set.

Examples

.s3.config["s3://flatfiles";`KX_S3_ENDPOINT`AWS_REGION!("https://files.massive.com";"us-east-1")]

Entity Details

.s3.config[scope;cfg]

Set the config of the paths under scope. A path takes the config of its longest scope that is a whole-component prefix (s3://flat does not cover s3://flatfiles/x), else the default's, and never a setting from another config. Each config is mirrored as a DuckDB secret of the same scope.

Return: (dict) the settings applied, the secret and the session token shown as "***"
Parameters:
  • cfg - (dict) text values keyed among AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY AWS_SESSION_TOKEN AWS_REGION AWS_PROFILE AWS_SHARED_CREDENTIALS_FILE AWS_CONFIG_FILE KX_S3_ENDPOINT KX_S3_USE_PATH_REQUEST_STYLE; :: for .s3.getAutoConfig[]; () drops the scopes
  • scope - (string|symbol|list) path prefixes sharing the config; :: is the default, "s3://"
throws:
  • domain - a scope that is not an s3://, s3a:// or s3n:// prefix
  • type - cfg is not a dict, :: or (), or a value is not text
  • option - a key that is not a setting

Examples

.s3.config["s3://flatfiles";()]

.s3.getAutoConfig[]

The settings the environment and the AWS shared files resolve to; later sources win: the config file's profile section ([profile p] or [default]), the credentials file's ([p]), then the environment. The key id, secret and token come whole from the last source holding a key id. AWS_REGION falls back to AWS_DEFAULT_REGION and KX_S3_ENDPOINT to the files' endpoint_url. The secret comes back as it is: this is an explicit call.

Return: (dict) a string per setting found, keyed by .s3.config's names

Examples

.s3.getAutoConfig[]

The config a path is read with, masked; the empty dict when nothing covers it.
