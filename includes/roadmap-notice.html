Roadmap: what doesn't work yet

PeachQ 0.92 reads and writes kdb+ on-disk data, including partitioned and segmented databases. The main gaps now are:

  • Performance. Queries on a partitioned database give correct results but are not yet efficient. Each query builds one in-memory table from the partitions it reads, so a large historical database (HDB) will be much slower than kdb+ and use far more memory.
  • Multi-threading. Query execution does not yet spread work across cores as kdb+ does.
  • Snappy-compressed and encrypted files do not read yet. gzip and lz4 do.
