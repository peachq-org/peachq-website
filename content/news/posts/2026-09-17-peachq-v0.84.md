# peachq v0.84 released

- q conformance rises from **83.9% to 84.5%**.
- Loading fixes cover TorQ, kdb-common, qutil/reQ, funq, qtips and qspec; full workload compatibility remains work in progress.

<!-- more -->

- Files loaded through functions use the function's namespace; trapped failures restore the session namespace.
- Scripts echo statement results; terminal startup failures enter the debug prompt with source locations.
- Temporal arithmetic, float-vector attributes, lookups, iteration and qSQL gain compatibility fixes.
- Windows parity checks pass all 935 measured suites; 30 non-portable suites were skipped.
